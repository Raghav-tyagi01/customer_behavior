
# Customer Behavior & Sales Analysis Dashboard


## 1. Short Description
This project focuses on analyzing customer purchasing behavior, sales performance, delivery efficiency, and product ratings using an e-commerce dataset.

The dashboard helps identify repeat customers, top-performing regions, product trends, and factors affecting customer satisfaction, enabling data-driven business decisions.
##  2. Tools and technologies used

Excel → Data cleaning & preprocessing.

SQL (MySQL) → Data analysis & querying.

Power BI → Data visualization & dashboard creation.

DAX → Calculated columns, KPIs, and measures.

## 3. Insights of the Dashboard
Track sales trends over time

Identify repeat vs one-time customers (customer retention)

Analyze top cities and states by sales and orders

Evaluate product category performance

Understand impact of delivery time on customer ratings

Detect delayed deliveries and logistics issues

## 4. Key Visuals

•📈 Line Chart → Sales trend over time

•🍩 Donut Chart → Repeat vs One-time customers

•📊 Bar Chart → Top cities by orders

•🗺️ Map → State-wise revenue

•📦 Column Chart → Category-wise sales & ratings

•🔵 Scatter Plot → Delivery days vs Rating

•🚚 Donut Chart → Delivery performance (Fast / Delayed
## 5. Key Questions the Dashboard Answers

• How many customers are repeat vs one-time buyers?

• Which cities generate the highest number of orders?

• Which product categories have low ratings?

• What is the average delivery time?

• Which orders are delayed (>5 days)?

• Does delivery delay affect customer ratings?

• Who are the top customers by revenue?

• What are the monthly sales trends?
